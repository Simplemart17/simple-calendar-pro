# calendar-web

Next.js frontend for SimpleCalendar.

## Environment
Create `.env.local` from `.env.local.example`.

Variable:
- `NEXT_PUBLIC_API_BASE_URL` (defaults to `http://localhost:4000`)

## Scripts
- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`
- `npm run typecheck`
- `npm run format`
- `npm run format:check`
